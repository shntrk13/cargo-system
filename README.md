📦 Hızlı Kargo

Python kullanarak geliştirdiğim basit bir kargo yönetim sistemidir.

Program üzerinden yeni gönderiler oluşturulabilir, oluşturulan gönderiler listelenebilir ve gün sonunda gönderilerle ilgili çeşitli istatistikler görüntülenebilir.

📌 Proje Özellikleri

Programda aşağıdaki işlemler yapılabilir:

* Yeni gönderi oluşturma
* Gönderileri listeleme
* Gün sonu raporu oluşturma
* Toplam gönderi sayısını görüntüleme
* Toplam kazancı hesaplama
* Ortalama gönderi ücretini hesaplama
* En pahalı gönderiyi bulma
* Standart ve hızlı teslimat sayılarını görüntüleme
* Küçük, orta ve büyük paket sayılarını görüntüleme

💰 Ücret Hesaplama

Gönderinin toplam ücreti birkaç farklı faktöre göre hesaplanır:

* Paket ağırlığı
* Paket hacmi
* Gönderilecek şehir
* Teslimat tipi

Ayrıca belirli ücret seviyelerinde indirim uygulanır ve hızlı teslimat seçildiğinde ek ücret hesaplanır.

📦 Paket Türleri

Paket hacmine göre üç farklı paket türü bulunmaktadır:

* Küçük Paket
* Orta Paket
* Büyük Paket

🚚 Teslimat Türleri

Programda iki farklı teslimat seçeneği bulunmaktadır:

* Standart Teslimat
* Hızlı Teslimat

Hızlı teslimat seçildiğinde toplam ücret üzerinden ek ücret hesaplanır.

📊 Gün Sonu Raporu

Programın gün sonu raporu aşağıdaki bilgileri gösterir:

* Toplam gönderi
* Toplam kazanç
* Standart teslimat sayısı
* Hızlı teslimat sayısı
* Küçük paket sayısı
* Orta paket sayısı
* Büyük paket sayısı
* Ortalama gönderi ücreti
* En pahalı gönderi

🧠 Kullanılan Python Konuları

Bu projeyi geliştirirken aşağıdaki Python konularını kullandım:

* Değişkenler
* Fonksiyonlar
* global
* if / elif / else
* Listeler
* Dictionary
* for döngüsü
* enumerate()
* input()
* int()
* F-string
* Aritmetik işlemler
* Koşullu fiyat hesaplama
